基于Qt/C++开发的跨平台音乐播放器，提供简洁美观的界面和丰富的音乐播放功能。
功能特点
支持多种音频格式(MP3, WAV, FLAC, M4A)播放
自定义无边框界面设计，支持主题定制
LRC歌词解析与同步显示功能
本地音乐库管理与播放列表支持
专辑封面显示与音乐元数据读取
歌曲标题滚动显示效果
音量控制与静音功能
播放进度拖拽调整
跨平台支持(Windows, macOS, Linux)

技术栈
C++
Qt Framework (Widgets, QMediaPlayer, QAudioOutput)
JSON数据处理
QSS样式表
正则表达式

环境要求
Qt 5.15.0或更高版本
C++14或更高版本支持的编译器
